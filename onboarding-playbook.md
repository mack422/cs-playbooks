# Onboarding Playbook

## Goal
Get a new customer to a first visible result quickly.

## Steps
Kick off with the daily users and the budget owner together. Confirm the goals and how success will be measured. Map integrations with the operations or IT group early, since security review is the usual source of delay. Walk users through the platform functionality they need first, using live sessions and in app walkthroughs. Run a customer webinar when several users need the same training. Review the first results with the sponsor.

## Checkpoints
Check in at 30, 60 and 90 days. Record CSAT at each point and fix gaps before the next review.
